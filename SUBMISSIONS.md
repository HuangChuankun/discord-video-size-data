# Where this data can be submitted

Five places that take submissions on topic, with the section the entry belongs in and the
line to paste. All five were checked on 2026-11-02: the repository exists, is not archived,
and either says it accepts pull requests or ships a `contributing.md`.

Nothing here has been submitted yet. Submitting needs a GitHub account, and no GitHub
session is signed in on the machine this was prepared on.

- 374 stars, last push 2026 (the README line "Welcome PR if you find some Awsome WebAssembly Applications")
- Section: `## Inside the browser` → `### Media` — the list already carries in-browser media tools with one-line descriptions
- Entry to paste:

```
- [ClipFit](https://compressmyclip.com/) — Browser-based Discord video compressor: works the bitrate out from the clip's length and the account's upload ceiling, encodes with ffmpeg.wasm, and reports the real output size. Nothing is uploaded.
```

## Two things that will sink any of these

- Pasting the same description into all five. Each list has its own house style; the lines above are already written in each one's format.
- Linking the repo *and* the site in the same line. One link per entry, the site link; the repo is what you send when someone asks for the data behind it.
